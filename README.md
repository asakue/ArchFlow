
# Система управления архитектурой ИТ-решений

## Описание проекта

Веб-приложение для управления архитектурой ИТ-решений организации, обеспечивающее эффективное планирование, документирование и контроль архитектурных решений.

### Основные возможности

- 📊 **Панель мониторинга**: Обзор ключевых метрик и статистики
- 📐 **Управление проектами**: Создание и ведение архитектурных проектов
- 📑 **Артефакты**: Управление архитектурными документами и артефактами
- ✅ **Согласование**: Процесс рассмотрения и утверждения архитектурных решений
- 📈 **Аналитика**: Детальная аналитика и отчетность
- 🎯 **Шаблоны**: Библиотека готовых архитектурных шаблонов

## Технологический стек

### Frontend
- React + TypeScript
- Vite
- TanStack Query
- Tailwind CSS
- Radix UI
- Recharts

### Backend
- Node.js + Express
- TypeScript
- Passport.js для аутентификации
- In-memory хранилище данных

## Установка и запуск

1. **Клонирование репозитория**
```bash
git clone <repository-url>
```

2. **Установка зависимостей**
```bash
npm install
```

3. **Запуск приложения в режиме разработки**
```bash
npm run dev
```

Приложение будет доступно по адресу: `http://localhost:5000`

## API Endpoints

### Аутентификация
- `POST /api/login` - Вход в систему
- `POST /api/register` - Регистрация пользователя
- `GET /api/user` - Получение данных текущего пользователя

### Проекты
- `GET /api/projects` - Список проектов
- `POST /api/projects` - Создание проекта
- `GET /api/projects/:id` - Получение проекта
- `PATCH /api/projects/:id` - Обновление проекта

### Артефакты
- `GET /api/artifacts` - Список артефактов
- `POST /api/artifacts` - Создание артефакта
- `GET /api/artifacts/:id` - Получение артефакта
- `PATCH /api/artifacts/:id` - Обновление артефакта

### Аналитика
- `GET /api/dashboard/stats` - Статистика панели мониторинга
- `GET /api/compliance/:projectId` - Данные о соответствии стандартам

```bash
npm install

# Установка зависимостей Backend

```

```bash

# Запуск Frontend (в директории frontend)
```

Frontend будет доступен по адресу: `http://localhost:5001`
